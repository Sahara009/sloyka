# Как добавить товар на сайт (обучалка)

Тренируемся на разделе **Sloyka Wish** (брелоки, бирки, подвесы): он появится в каталоге и на главной сам, как только в нём будет хотя бы один товар. Так же добавляются товары в любые другие направления.

Сейчас товары лежат в одном файле, `src/data/products.ts`. Админка (`/admin`) умеет менять цену, наличие и «хит», но не создаёт новые товары.

## 1. Подготовить фото

- Формат **WebP** (или PNG). Сжать можно на squoosh.app: качество ~80, ширина до 1200 px.
- **Вырезанный товар на прозрачном фоне** → папка `public/products/`. **Фото в интерьере или с фоном** → `public/photos/`.
- Имя файла: латиницей, через дефис, например `keychain-logo.webp`. Если фото несколько: `keychain-logo-2.webp`.
- Для товаров с раздельными цветами (столешница, ножка…): отдельный файл на каждую деталь, анфас, одна камера и масштаб, прозрачный фон.

## 2. Пересчитать размеры картинок

```
npm run images
```

Команда сама обновит `src/data/images.ts` (размеры нужны, чтобы страница не прыгала при загрузке). Запускай после каждого нового фото.

## 3. Описать товар

Открыть `src/data/products.ts`, найти блок `wishProducts` (или нужное направление) и добавить товар:

```ts
{
  slug: "keychain-logo",            // адрес страницы: /catalog/keychain-logo (латиница, без пробелов, уникальный)
  name: "Брелок с логотипом",
  line: "wish",                     // home | market | podium | topper | wish
  series: "wish",                   // подраздел (см. тип Series в начале файла)
  kind: "decor",                    // set | stand | part | base | podium | decor (раздел в фильтре каталога)
  price: 250,                       // минимальная цена; null = «по запросу»
  short: "Именной брелок для клиентов кондитера",   // одна строка на карточке
  description: "Подробное описание …",
  specs: ["Материал: экологичный пластик", "Размер: 5 см"],
  image: img("keychain-logo"),      // файл из public/products/  (для public/photos/ — photo("…"))
  gallery: [img("keychain-logo-2")],// дополнительные фото, можно не указывать
  colors: "one",                    // один цвет из палитры; "two" — два; "none" — без выбора цвета
  hit: true,                        // метка «хит» (необязательно)
  isNew: true,                      // метка «new» (необязательно)
},
```

Дополнительно, если нужно:

| Что | Как |
|---|---|
| Размеры или варианты с разной ценой | `options: [{ id: "s", label: "S", price: 250 }, { id: "m", label: "M", price: 350 }]` |
| Свои зоны цвета (столешница, ножка, крышка…) | `zones: [{ id: "top", label: "Столешница" }, { id: "leg", label: "Ножка" }]` |
| Слои деталей для перекраски | у каждой зоны `layer: img("имя-детали")` |
| Логотип за доплату | `logoAddon: true` (цена зависит от размера, см. `logoPrice`) |
| Другое фото для размера | в `options` поле `image` |
| Цена «по запросу» (кастом) | `price: null` |

## 4. Посмотреть у себя

```
npm run dev
```

Открыть `http://localhost:3000/catalog?line=wish`: карточка должна быть в каталоге, на странице товара работают цвета и цена, на главной в «Наших линейках» появится карточка Wish.

## 5. Выложить

1. Закоммитить и запушить в GitHub: сборка демо запустится сама (вкладка Actions), через 2–3 минуты ссылка обновится.
2. Если каталог работает из базы (`CATALOG_SOURCE=db`), после правок выполнить `npm run db:seed`.

## Проверочный список

- [ ] Фото в `public/products/` или `public/photos/`, имя латиницей
- [ ] `npm run images` выполнен
- [ ] `slug` уникальный
- [ ] Цена, короткое описание и состав заполнены
- [ ] В `npm run dev` страница товара открывается, цвета и цена работают
- [ ] Правила для кастома (логотипы, вывески, топперы с нуля) идут через личку: `price: null`
