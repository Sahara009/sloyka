# Sloyka — сайт (Next.js)

Сайт Sloyka: десертные столики Sloyka Home, подставки Classic Cakestand, Design Stand и подиумы, стенды Sloyka Market, Art Decor Waffle's, вывески. Каталог, конструктор сборки, корзина с оплатой Т-Банк (карта и СБП) и доставкой СДЭК и Ozon.

## Запуск

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # проверка сборки
```

Для ключей скопируй `.env.example` в `.env.local`. Без ключей сайт работает в демо-режиме: заказ принимается, но оплата не создаётся.

## Страницы

| Путь | Что на странице |
|---|---|
| `/` | Главная |
| `/catalog`, `/catalog/[slug]` | Каталог и карточка товара |
| `/constructor` | Конструктор: столик (Home) и стенд (Market). `?preset=slug` открывает готовую сборку, `?line=market` сразу открывает стенды |
| `/cart` | Корзина и оформление заказа |
| `/business` | Для бизнеса: декор и заявка |
| `/delivery` | Доставка и оплата |
| `/about` | История бренда (сейчас тексты-заглушки) |
| `/contacts` | Контакты и форма |
| `/legal/privacy`, `/offer`, `/consent`, `/cookies` | Юридические шаблоны |

## Структура

```
src/
  app/                  страницы (App Router) и API: /api/orders, /api/requests
  components/
    art/                ProductVisual (фото или SVG), SVG-превью для конструктора
    cart/               корзина (localStorage), кнопка «В корзину», оформление
    catalog/            карточка товара, фильтры каталога
    constructor/        конструктор Home и Market с правилами совместимости
    consent/            cookie-баннер, согласие, Яндекс Метрика только после согласия
    layout/             шапка и подвал
    preloader/          прелоадер «глазурь» (стекающие слои), генератор подтёков drip.ts
    ui/                 Shape (маски), Photo, Reveal (появление при скролле), Drip, Ticker, Swatches, формы
  data/                 палитра (25 цветов), детали и цены, товары, юр. тексты
  lib/                  форматирование, интеграции (tbank.ts, delivery.ts)
  styles/               tokens.css (цвета и шрифты), patterns.css (полоски, клетка, фестоны, маски)
public/products/        фото товаров без фона (WebP), вырезаны со скринов сторис
public/photos/          интерьерные фото и кадры из инстаграма
public/shapes/          SVG-формы для масок: quatrefoil, clover, scallop, arch, arch-scallop, cloud, stamp, ornate
```

## Дизайн

- Цвета лежат в `src/styles/tokens.css`. Основа нежно-голубая и молочная, акценты: шоколад, бордо, карамель, нежно-зелёный.
- Полоски и клетка заданы классами `bg-stripes-blue`, `bg-stripes-sage`, `bg-stripes-caramel`, `bg-gingham`.
- Фигурные маски: `<Shape shape="quatrefoil" outline="var(--blue-400)" bg="var(--blue-100)">…</Shape>`. Новая форма — это SVG-файл в `public/shapes`.
- Шрифты подключаются в `src/app/fonts.ts`. Сейчас стоят Cormorant Garamond, Manrope и Bad Script как рукописный акцент. Клиент ещё выбирает, меняются в одном файле.

## Варианты оформления (временно)

Два стиля: «Мягкий» (тонкие линии) и «С обводкой» (шоколадный контур граней, как в референсе Pigice). Переключатель внизу слева, ссылка для заказчика: `/?style=outline` или `/?style=soft`. Когда выберет — в `src/data/themes.ts` поставить `DEFAULT_THEME` и `THEME_SWITCHER = false`. Стили обводки — `src/styles/outline.css`.

## Анимации

- Прелоадер: `components/preloader`. Показывается один раз за визит, при `prefers-reduced-motion` просто плавно исчезает. Цвета слоёв — в `Preloader.tsx`.
- Появление при скролле: `<Reveal effect="up | fade | scale | left | right | drip" delay={мс}>…</Reveal>`. Стили — `styles/motion.css`.

## Фото

- Фото вырезаны со скриншотов сторис, поэтому мелкие и местами с неровными краями. Когда будут оригиналы, достаточно заменить файл в `public/products` с тем же именем и обновить размеры в `src/data/images.ts`.
- У товара: `image` — главное фото, `gallery` — дополнительные, `variants` — глазурь с фото (Waffle's), `options` — размеры с ценами.

## Конструктор и перекраска

- Превью собирается из фото деталей в **белом** пластике без фона (`public/products/base/*.webp`) и перекрашивается в любой из 25 цветов (`components/ui/Tinted.tsx`: слой цвета по силуэту детали в режиме multiply — тени и рельеф остаются).
- Для тёмных цветов (шоколад, бордо) перекраска хуже — можно положить настоящее фото детали в этом цвете: `photos` в `src/data/visuals.ts` (потом — поле `colorPhotos` у детали в админке).
- Как детали стоят друг на друге: `width` (ширина на сцене) и `tuck` (какая доля высоты уходит под деталь сверху) — там же.
- **Как снимать детали:** каждая деталь отдельно, в белом, сбоку на уровне глаз, на однотонном фоне, с одного расстояния и одним объективом (тогда масштаб у всех одинаковый). Новый файл с тем же именем заменяет черновой.
- Код сборки (например `H-FLE-MUF-PUM-0-0kc`) открывает ту же сборку по ссылке `/constructor?b=…` — его удобно прислать в директ.

## Доставка и оплата

| Что | Где |
|---|---|
| Коробки S/M/L, вес и габариты деталей, зоны Ozon/WB | `src/data/shipping.ts` (черновые цифры) → модели `Box`, `DeliveryZone`, поля веса у `Part`/`Product` |
| Подбор коробки на заказ | `src/lib/shipping.ts → pack()`: самая маленькая, куда всё влезает; ножки и вкладыши «вкладываются» |
| Расчёт для корзины | `POST /api/delivery/quote` — СДЭК точно по API (если есть ключи), Ozon/WB — вилка «≈ от–до» по городу |
| Коробку в заказе можно поменять | админка → заказ → «Упаковка» |
| Оплата | `src/lib/integrations/payments.ts`: ЮKassa (для самозанятых) или Т-Банк, переключатель `PAYMENT_PROVIDER` |
| Подтверждение оплаты ЮKassa | `POST /api/payments/yookassa` (статус перепроверяется запросом в ЮKassa) |

Покупатель оплачивает товары; доставку менеджер подтверждает после взвешивания (на сайте она с «≈»).

## Бэкенд, база и админка

Сайт работает и без базы — на данных из `src/data`. Всё для перехода на базу уже готово:

| Что | Где |
|---|---|
| Схема базы (товары, детали, цвета, заказы, заявки, кейсы) | `prisma/schema.prisma` |
| Перенос каталога из файлов в базу | `prisma/seed.ts` → `npm run db:seed` |
| Подключение к базе | `src/lib/server/db.ts` |
| Каталог из файлов или из базы | `src/lib/server/catalog.ts` (переключатель `CATALOG_SOURCE`) |
| Пересчёт цен на сервере | `src/lib/pricing.ts` — цене из браузера не доверяем |
| Заказы и заявки | `/api/orders`, `/api/requests` — сохраняются в базу |
| Админ-панель | `/admin`: обзор, заказы (статус, трек-номер), заявки, товары (цена, наличие, хит) |

### Как включить

1. Создать базу PostgreSQL (Neon / Supabase / Timeweb Cloud — у всех есть бесплатный тариф) и вписать `DATABASE_URL` в `.env.local`.
2. `npm install` (сам выполнит `prisma generate`), затем `npm run db:push` и `npm run db:seed`.
3. Задать `ADMIN_PASSWORD` и `ADMIN_SECRET` → войти на `/admin/login`.
4. Чтобы цены и товары правились в админке, поставить `CATALOG_SOURCE=db`.

### Дальше

1. Полная форма товара в админке: описание, размеры, фото (загрузка в S3 / Yandex Object Storage).
2. Детали конструктора и цвета из базы (модели `Part`, `Color` уже есть).
3. Формы редактирования коробок, зон и деталей (с загрузкой фото в белом) — сейчас `/admin/shipping` только показывает.
4. СДЭК: виджет ПВЗ и создание отправления после оплаты.
5. Уведомления о заказах и заявках в Telegram.

## Демо на GitHub Pages (чтобы заказчик сам посмотрел и потыкал)

Это статическая копия сайта: без сервера и базы. Поиск и расчёт доставки работают в браузере, заказы и заявки **никуда не отправляются** (на сайте видна плашка «демо-версия»). Админки и оплаты в демо нет.

1. Создайте репозиторий на GitHub (например `sloyka.home`) и загрузите проект: `git init`, `git add .`, `git commit -m "Sloyka"`, `git branch -M main`, `git remote add origin <адрес>`, `git push -u origin main`.
2. В репозитории: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. После пуша во вкладке **Actions** запустится «Демо на GitHub Pages» (2–3 минуты). Готовая ссылка: `https://<ваш-логин>.github.io/<имя-репозитория>/`.
4. На бесплатном тарифе GitHub Pages работает только с публичным репозиторием; секретов в проекте нет (`.env.local` в `.gitignore`), но пароли и ключи в код не вписывайте.

Проверить локально: `npm run build:demo`, затем `npx serve out` (при сборке без аргумента адрес — в корне; для подпапки: `node scripts/build-demo.mjs /sloyka.home`).
